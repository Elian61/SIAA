Innovación Tecnológica — ActuNova

Descripción

Espacio destinado a organizar la documentación técnica, los proyectos de desarrollo y los recursos tecnológicos de ActuNova.

Contenido

* Especificaciones y documentación de sistemas.
* Archivos de pruebas y validaciones.
* Documentación del Sistema Integral Actuarial ActuNova (SIAA).
* Recursos relacionados con la automatización de cálculos actuariales.
* Documentación de integración con el área de Reservas.

Colaboración

Esta área trabaja en conjunto con Reservas para desarrollar, implementar y validar herramientas que permitan optimizar los procesos actuariales.

Control documental

Los archivos deberán mantenerse organizados y actualizados, respetando las versiones y responsabilidades del equipo.
